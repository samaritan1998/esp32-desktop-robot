# 发布验证记录

日期：2026-10-24。仓库首个公开版本，模型为 WALL-E 风格首版和 Marvin V4 一次代打版。

## 几何与可再生成性

- 从公开 Python 源码和参数重新生成，两套模型的 **25 个可打印 STL 分件**（WALL-E 10，Marvin 正式件 9＋备用件 6）与发布文件逐字节一致。
- 检查网格封闭性、绕序、正体积、单一连通和打印底面 Z＝0。模型生成器还执行整机分件干涉检查；详细几何报告在各模型目录。
- Marvin 3MF 通过 ZIP 完整性、毫米单位、15 个不同网格和 20 个打印实例检查；重新生成的几何与放置 XML 一致。独立使用 trimesh 读取确认数量、封闭性及 180 mm 范围。
- GLB 预览使用米作为单位；打印 STL／3MF 使用毫米。WALL-E 旧预览的单位已在公开副本中规范化，打印分件不变。
- OpenSCAD 源已提供，但没有在 OpenSCAD 编译器中另行导出验证；没有宣称完成打印机切片的逐层检查。

摘要：[model-validation.json](model-validation.json)。复现命令（仓库根目录）：

```sh
python3 -m pip install -r requirements-tools.txt
python3 tools/validate_models.py
```

## 固件与字模

- 原系统字体字模未进入公开源码。已使用固定提交、固定 SHA256 的 Noto Sans CJK SC 生成 Robot UI Bitmap，并随附原字体版权与 SIL OFL 1.1 全文。
- Marvin 80 个字符、WALL-E 76 个字符，各生成 16／18／28／36 四种尺寸；生成时检查字模非空。
- C++ 桌面渲染覆盖每个角色 10 个表情状态、6 个抽签结果，共 32 帧；检查画布边界并人工查看接触表。
- 在固定小智 v2.5.2 源码上应用公开补丁，确认两个独立板型映射，不覆盖官方板型。使用 ESP-IDF v6.1.0、ESP32-S3 工具链检查构建。
- 上游主机测试 **110 项通过**。本机 macOS 标准 C++ 头文件搜索路径需显式配置；修正本机环境后全部通过，未修改上游测试。

构建摘要见 [firmware-validation.json](firmware-validation.json)。初次构建复用了本机已有的托管依赖缓存，没有将该缓存加入仓库；公开源码准备工具也提供独立下载及归档校验路径。

## 实物验证的边界

- 制作者此前确认：WALL-E 外壳能装入其屏幕；两个角色的前期固件能显示、触摸、识别动作、抽签、联网识别语音并播放 AI 回答。
- **Marvin V4 外壳尚未实物装配确认。**已知原装壳名义尺寸和设计包络不等于测量了用户样品。代打方、材料与打印补偿也影响实际配合。
- 本次公开固件改用了开源字模。修改后的版本在本机检查构建与图形，**尚未重新刷入实机复测**；没有新增硬件、音频或网络功能。
- 未验证装入新 Marvin 外壳后的实际收音与音量，也未验证 iPhone USB 音箱。USB 播客实验未完成，不包含在此版本。

本次发布提供源码和可打印模型，**不附宣称已实机验证的刷机二进制**。设备完整备份、联网设置、账号信息及私人日志不在公开目录内。
