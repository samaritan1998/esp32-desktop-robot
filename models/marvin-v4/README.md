# Marvin V4 一次代打包

打印后请参照 [装配说明](装配说明.md) 安装，尤其注意屏幕朝向、软垫和 USB 接线顺序。

**把整个压缩包和《转给朋友_一次代打.txt》交给朋友，一次打印正式零件与所有备用小件。**本包不要求你另约一轮打印试片。

## 做准的依据

首位制作者反馈本仓库的 WALL-E 风格外壳可以装入其带原装黑壳的屏幕。将那套源文件重新生成并核对头壳 STL 完全一致后，再把装板空间对齐到 Marvin 检查：

| 装配尺寸 | 那版瓦力 | 本版 Marvin |
|---|---:|---:|
| 屏幕开窗 | 36.5 × 31.1 毫米，圆角5.1 | 相同 |
| 装入通道 | 44.8 × 37.8 毫米，圆角 | 47.6 × 41.6 毫米，矩形避让 |
| 前框到后盖接触柱可用深度 | 19.8 毫米 | 21.8 毫米 |

对齐后的瓦力可用空间与 Marvin 前、后头壳都没有体积碰撞。完整记录见《与已能装的瓦力尺寸比对.json》。这是对已报告能装的参考模型做数字比对，尚未测量该制作者的黑壳，也未在代打方的打印机上进行实物装配。

## 一次打齐什么

- 正式零件01—09各一件。
- 0.6、1.0、1.4、1.8、2.2毫米条垫各两条，按实际间隙选其中一档使用。上下两条前面都要有薄软垫，不能用硬塑料强压黑壳。
- 09b较松的备用脖子一件，替代标准09使用；两种脖子只装一种。

共15个不同的STL、20个打印实例。条垫和备用脖子总用料很少，目的是装配时就能调整。`一次打印排版_180mm.3mf` 已包含全部数量和原建议方向，毫米单位，排版在180毫米见方范围内；朋友可以依自己的打印机分盘安排。它是通用几何文件，支撑和打印参数仍要由朋友切片设置。

## 怎么交付最稳妥

如果方便，**把带黑壳的屏幕一起交给朋友，让他交付前装板确认**。这样你仍然只需要取一次完整成品，测量与调整也能在打印端解决。

若朋友拿不到实物，就让他先把身体、四肢、脖子和头盖干装检查好，并将所有备用小件、螺丝与泡棉一起交回。回来只需选垫片厚度和装板。

本包已完成几何检查；实际黑壳和这台打印机尚未共同验证，因此不能承诺100%一次成功。相比继续盲目改大，沿用成功开窗、扩大内部通道并备齐调节件能减少补打的可能。

整机约84 × 48 × 100毫米。正式头壳就是V4，不需要重刷屏幕程序。已有V3身体与四肢仍可复用，01/02必须用同一版V4。
